# Full-Stack EMS (Employee Management System)

Employee Management System with React 19, TypeScript, Tailwind CSS & React Router

## Description

A comprehensive Employee Management System built with modern web technologies. Manage employee information, track schedules, and streamline HR operations with an intuitive interface.

## Technologies Used

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM v7
- **UI Components:** Lucide React Icons
- **Notifications:** React Hot Toast
- **Code Quality:** ESLint

## Features

- Employee CRUD operations
- Employee database management
- Responsive and modern UI
- Real-time notifications
- Easy navigation with React Router
- Icon-rich interface with Lucide icons

## Getting Started

### Prerequisites
- Node.js and npm installed

### Installation

```bash
# Install dependencies
npm install

# Start development server in client directory
cd client
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
